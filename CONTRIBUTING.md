# Contributing

Thank you for helping make Arthodaya better for first-time investors across India.

---

## Quick Start

1. **Fork** the repository
2. **Create a branch:** `git checkout -b feat/short-name` (or `fix/`, `docs/`)
3. **Make changes** — keep the app dependency-free and single-file unless a split is agreed in an issue
4. **Run tests:** `npm test` before committing
5. **Commit** with a short imperative message, e.g. `Add Marathi term translations`
6. **Open a pull request** using the template

---

## Definition of Done

- [ ] Works at **360px width** and with **keyboard only**
- [ ] No new network calls without being documented in `ARCHITECTURE.md`
- [ ] Passes every rule in `GUARDRAILS.md`
- [ ] Any change touching quiz, scam, or advice text needs a **second reviewer**
